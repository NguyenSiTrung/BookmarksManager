Bookmarks Manager Privacy Source Support

Your bookmarks, organized — on your device.

Bookmarks Manager is a Chrome extension that replaces the built-in bookmark manager with fast search, tags, categories, notes, undo, and import/export. Everything runs locally. An optional AI provider connection — off by default — can help organize on your request.

View on GitHub

Local-first

No accounts, no sign-in, no telemetry, no developer servers. Your bookmark metadata lives in your browser's IndexedDB and never leaves the device unless you start a provider feature yourself.

Fast search everywhere

A side panel, command palette, popup, and bm omnibox keyword all query an in-memory index — search produces zero network requests.

Optional AI, your rules

Pin a Jev 1.13 model or configure one OpenAI-compatible endpoint. Consent is per-scope and versioned, keys are AES-GCM encrypted at rest, and revoking deletes every grant.

Safe by design

Move, merge, and restructure operations are never auto-applied. Destructive changes take undo snapshots. No data is sold, shared for advertising, or read by humans.
